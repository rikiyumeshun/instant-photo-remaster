# Manual Test Checklist

スマホ実機で公開URLを開き、以下を確認します。

## 入力

- 通常JPEGをアップロードし、プレビューと四隅調整が表示される。
- 20MB超の巨大画像で警告Toastが表示され、読み込みが続行される。
- HEIC / HEIF画像をアップロードし、ブラウザ内でJPEGへ変換されて読み込める。
- 壊れた画像または非対応形式で、JPEG / PNG / WebP / HEICを案内するエラーが出る。

## 補正

- ローカル高速補正でプレビューが作成できる。
- スマホ内AI風補正の標準 / 高品質 / 最高品質を切り替えられる。
- 大きい画像で最高品質を選んだとき、高品質へ自動フォールバックする警告が出る。
- 最高品質失敗時に「高品質で再試行」の導線が出る。

## サーバーAI

- 正しいアクセスコードでAI補正が成功する。
- アクセスコード未入力で、送信前に入力エラーが出る。
- 間違ったアクセスコードで専用エラーが出る。
- Renderスリープ後の初回AI補正で、起動待ちの文言が表示される。
- タイムアウトまたはネットワーク遮断時に、ローカル補正への復帰導線が出る。
- AI補正中にキャンセルできる。

## 保存と共有

- 補正後画像を保存できる。
- 比較画像を保存できる。
- Web Share API対応端末で共有できる。
- 共有キャンセルが赤エラー扱いにならない。
- 共有非対応ブラウザでは保存へフォールバックする。
